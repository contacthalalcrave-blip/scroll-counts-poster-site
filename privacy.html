Privacy Policy — Scroll Counts Poster

Last updated: [Sept 19, 2026]

Scroll Counts Poster is a personal automation tool used solely by its developer to publish promotional content to a single TikTok account on behalf of the Scroll Counts iOS app.

What data this tool accesses

Through TikTok's Content Posting API, this tool accesses only the OAuth access token and basic account identifier for the single TikTok account it is authorized to post to. This access is used exclusively to upload image content to that account's TikTok draft inbox.

What this tool does not do

  • It does not collect, store, or process data from any TikTok user other than the single account it is authorized for.
  • It does not share any data with third parties.
  • It does not use TikTok data for advertising, profiling, or any purpose other than posting the developer's own content.

Data storage

Access credentials are stored locally and used only to authenticate API requests. No TikTok user data is retained beyond what is required to complete each post upload.
